# Cotizador MEGA

Cotizador y comparador para asesores de MEGA en Cancún: captura lo que el cliente paga hoy, arma su paquete MEGA con extras y genera dos imágenes para compartir (comparativa y pagos mes a mes).

## Cómo cambiar precios

Los precios viven en `catalogo.json`. Para que todos vean un precio nuevo:

1. Abre el cotizador, cambia los precios en **Mi catálogo** y pulsa **Descargar catalogo.json**.
2. En este repositorio, abre `catalogo.json`, pulsa el lápiz (editar) o sube el archivo nuevo para reemplazarlo, y guarda los cambios.
3. En uno o dos minutos el cotizador se actualiza para todos.

Los cambios hechos solo en **Mi catálogo** se quedan en ese dispositivo hasta que se sube un `catalogo.json` nuevo.
